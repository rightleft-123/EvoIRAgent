# EvoIR-Agent: Self-Evolving Image Restoration Agentic System via Experience-Driven Learning


## Overview
This is the official code repository for the paper **"EvoIR-Agent: Self-Evolving Image Restoration Agentic System via Experience-Driven Learning"**.

**🔔 Open Source Commitment:** 
We are fully committed to the open-source community. All materials, including:
- The complete implementation of the EvoIR-Agentic system
- The experience-driven learning framework and memory database
- Evaluation scripts and pre-trained models
- Dataset preparation and synthesis tools
